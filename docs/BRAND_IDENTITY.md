# Brand Identity

**Name:** Telosieve  -  “telos” (purpose) plus “sieve,” describing scrutiny of an
instruction before enforcement.

**Tagline:** Question the instruction before enforcing it.

The voice is precise, skeptical, calm, and claim-safe. Avoid sentience, immune
system, infallibility, and self-healing superlatives. A future visual direction may
use three distinct evidence strands passing through a verification aperture, but
logo, palette, typography, domains, and public launch assets are deferred until
the validation gate.

The 2026-07-29 preliminary collision sweep found no exact Telosieve project,
GitHub account/repository, npm package, or prominent web use. Package and domain
availability are not reserved; trademark clearance was not performed.
